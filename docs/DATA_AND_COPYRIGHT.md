# Data and copyright boundary

This software repository contains no publisher PDF, HTML or XML full text from the evaluated corpus, no article figure or table, and no substantial verbatim passage from a source report.

Users must obtain source reports through lawful publisher or repository routes and are responsible for complying with the applicable licence and terms of use. The MIT licence in this repository applies only to the study-generated software and documentation; it grants no rights to third-party publications.

The associated manuscript supplements will provide rights-cleared bibliographic metadata, schemas, derived evaluation values, manifests and hashes. Where a source-text excerpt cannot be redistributed safely, the public derivative will use a report identifier and structural locator instead.

No patient-level data, hospital record, image, biospecimen or identifiable participant information is included in this release.
